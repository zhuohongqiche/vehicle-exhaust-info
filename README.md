# 汽车尾气排放与治理 · 行业信息手册

以公开权威资料整理的汽车尾气行业信息静态网站，覆盖：

- 尾气污染物构成与来源（生态环境部《中国移动源环境管理年报》数据）
- 排放标准演进（国一 → 国六b，国七预研）
- 在用车尾气检测方法与依据（GB 18285-2018 / GB 3847-2018 / OBD）
- I/M 制度闭环（I站 检验 → M站 维修 → 复检）
- 尾气超标常见原因与治理技术
- 行业趋势与车主常见问题 FAQ
- **行业动态 · 每日简报**（news.html）：每天按中央级 / 长沙本地 / 主管部门 / 交管公安四类权威来源，自动抓取政府政务、交通保通保畅、生态环境（禁烧/尾气）、车险监管、本地民生五类主题并归档，配套每日简报自动化任务（每日 07:30）更新。

纯静态站点（HTML/CSS/JS 自包含，无外部依赖），已部署于 GitHub Pages 与 WorkBuddy 静态空间。
